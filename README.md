# Canvas & Culture – Art Gallery Website

A multi-page art gallery website built with HTML, CSS and JavaScript.

## Pages (9)
1. `index.html` – Login page
2. `signup.html` – Sign Up page
3. `art-gallery-official.html` – Gallery Home page (search, filters, details pop-up)
4. `art-display.html` – Art Display page (list of all art pieces)
5. `art1.html` to `art5.html` – Individual art pages (Starry Night, Mona Lisa, The Persistence of Memory, Girl with a Pearl Earring, The Scream)

## Run locally
Open `index.html` in a browser. Sign up first, then log in.
(Accounts are stored in the browser's localStorage – demo only, not real authentication.)
